Защита от разбора

Что не разбирать и не сдавать на скрип ни при каких условиях: уникальные именные предметы разработчиков и годролы (предмет минимум с 3★, где каждая из звёзд 1–3 «хорошая»; 4★ не в счёт, два хороших эффекта — обычный предмет; «хорошие» эффекты задаются по типу и звезде, варианты через |). Страница «Вес» не даёт таким предметам советов. Приоритет персонажей для выученных модов задаётся в «Настройки → Персонажи и теги».

Правила разбора и передачи

Включён форк мода: правила разбора и передачи (в том числе цепочка легендарок по приоритету персонажей) ведутся на странице «Действия» — шаблоны chain-scrap, chain-give, chain-take. Правила LegeScrap по персонажам

Эффект, который не выучил кто-то из персонажей, достаётся персонажу с наивысшим приоритетом из невыучивших; остальные его не разбирают. Для каждого персонажа строится своё правило LegeScrap (та же клавиша, привязка к имени): исключения = эффекты, нужные другому, плюс прежний ручной список. Годролы и уникальные правило разобрать не может (мод не умеет «все три звезды хорошие»): защищайте их в игре избранным или блокировкой — в таблице справа ⚠ отмечены предметы без отметки. Годролы и уникальные дополнительно защищаются по названию: приложение записывает их в scrapProtection.itemNames. Запись в inventOmaticStashConfig.json делается с бэкапом и только по кнопке.
