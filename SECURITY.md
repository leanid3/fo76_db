# Безопасность

## Модель угроз

fo76db — локальная утилита: по умолчанию сервер слушает только `127.0.0.1`. Доступ из сети (`host` ≠ loopback)
разрешён только с токеном (`token` в `config.toml` или `FO76DB_TOKEN`); без него `serve` не запускается.
Запись путей, конфига IOM, очистка лога и скачивание копии базы доступны только с локального адреса.
Подробности — `CHANGELOG.md`, раздел «Безопасность».

## Сообщить об уязвимости

Откройте приватное уведомление на GitHub (Security → Report a vulnerability) или напишите владельцу репозитория.
Публичные issue для уязвимостей не используйте. В сообщении укажите версию (`fo76db doctor`) и шаги воспроизведения.
