# API для сторонних фронтендов

FO76 DB — обычное FastAPI-приложение, схема OpenAPI 3 строится из кода.

- **Живая схема:** `GET /openapi.json`; интерактивная документация — `/docs` (Swagger) и `/redoc`.
- **Файл в репозитории:** `docs/openapi.json`. Обновить: `fo76db openapi` (`-o файл`, `-o -` — в stdout). Обновляйте после изменения API.
- В схему входят только JSON-методы (`/api/...`); HTML-страницы, `/login`, манифест PWA и service worker исключены. Теги — по группам путей (`items`, `inventory`, `rolls`, …).

## Доступ

| Откуда | Что нужно |
|---|---|
| Этот компьютер (127.0.0.1, без прокси) | ничего |
| Сеть, токен не задан | ничего (но `serve` на не-loopback адресе без токена не запустится) |
| Сеть, токен задан | `Authorization: Bearer <токен>` (или cookie `fo76db_token`, или разовый `?token=`) |

Токен и режим сети — «Настройки → Доступ по сети» (см. `docs/pwa.md`). Без токена ответ `401`.

Методы записи путей, настроек сети, конфига IOM, окна выбора и очистки журнала доступны только с этого компьютера (`403` из сети, даже с токеном).

## Браузерный фронтенд на другом адресе

Запросы с другого origin блокирует браузер (CORS), поэтому адрес фронтенда нужно разрешить в `config.toml`:

```toml
cors_origins = ["http://localhost:5173"]
```

Затем перезапустите `serve`. Изменяющие запросы (POST/PUT/DELETE) с чужого `Origin` отклоняются защитой от CSRF (`403`), если в них нет заголовка
`Authorization: Bearer` — поэтому с чужого origin пишущие вызовы работают только по токену. Токен не должен попадать в код фронтенда,
который открывают другие люди: он даёт те же права, что и вход в сеть.

## Генерация клиента

```sh
fo76db openapi -o /tmp/fo76.json
npx @hey-api/openapi-ts -i /tmp/fo76.json -o src/client          # TypeScript
openapi-python-client generate --path /tmp/fo76.json             # Python
```

Ограничение: многие методы принимают тело как `dict` и возвращают произвольный JSON, поэтому типы в сгенерированном клиенте будут слабыми
(`object`/`any`). Точный состав полей смотрите в `docs/architecture.md` и в ответах `/docs`.

## Стабильность

API внутренний: версия схемы совпадает с версией утилиты, обратная совместимость между релизами не гарантируется.
