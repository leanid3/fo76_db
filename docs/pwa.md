# PWA: FO76 DB как приложение (ПК и телефон)

Веб-интерфейс устанавливается как приложение (PWA): своя иконка, отдельное окно без адресной строки. Без связи с сервером
показываются последние открытые страницы. Сервер остаётся на компьютере (`fo76db serve` или десктоп-версия), PWA — только окно к нему.

## На этом же компьютере

Откройте `http://127.0.0.1:7676` в Chrome, Edge, Chromium, Яндекс Браузере или Vivaldi и нажмите значок «Установить» в адресной строке
(или меню → «Установить FO76 DB»). Адрес `127.0.0.1` браузер считает безопасным, поэтому HTTPS здесь не нужен.
Firefox на ПК PWA не устанавливает. Окно без браузера даёт и [десктоп-версия](packaging.md#десктоп-версия).

## На телефоне

Браузер устанавливает PWA и включает офлайн-режим (service worker) **только по HTTPS с доверенным сертификатом**. По голому
`http://192.168.x.x:7676` страница откроется, но приложением не станет. Кроме того, сервер, открытый в сеть, должен быть
защищён **токеном**.

### 1. Токен

```sh
python -c "import secrets; print(secrets.token_urlsafe(24))"
```

Проще всего: «Настройки → Доступ по сети» → «Локальная сеть» (токен создастся сам, `data/network.json`). Вручную: результат запишите в `config.toml` как `token = "..."` (или задайте переменную `FO76DB_TOKEN`) и перезапустите сервер.

- Запросы с этого компьютера напрямую (`127.0.0.1`, без прокси) токен не спрашивают.
- Все остальные — телефон, другой ПК, обратный прокси, Docker с пробросом порта — без токена попадают на страницу входа `/login`,
  а API отвечает 401.
- Войти можно один раз по ссылке `https://<адрес>/home?token=<токен>` или через форму. Дальше работает cookie на год.
- Без токена `serve --host 0.0.0.0` (любой не-loopback адрес) отказывается запускаться: сервер был бы открыт всем в сети, а в утилите
  есть запись конфига IOM и запуск загрузок. Проверку снимает `FO76DB_ALLOW_OPEN=1` (в `compose.yaml` она задана: порт проброшен только на 127.0.0.1).
- Даже с токеном запись путей (`/api/paths`), окно выбора, запись и откат конфига IOM и очистка журнала доступны только с этого компьютера (403 с телефона).
- Изменяющие запросы (POST/PUT/DELETE) принимаются только со страниц этого же сайта (`Sec-Fetch-Site`/`Origin`), иначе 403 — защита от CSRF.
- Ответы несут `X-Content-Type-Options: nosniff`, `Referrer-Policy: no-referrer`, `frame-ancestors 'none'`. После 5 неверных токенов с одного адреса `/login` отвечает 429 на 5 минут.

### 2. HTTPS — один из вариантов

**Tailscale (рекомендуется).** Бесплатно для личного использования, сертификат настоящий, работает и вне дома, порт в интернет
не открывается.

1. Установите [Tailscale](https://tailscale.com/download) на компьютер и телефон, войдите в один аккаунт.
2. В панели Tailscale включите MagicDNS и HTTPS Certificates (DNS → HTTPS).
3. На компьютере:
   ```sh
   tailscale serve --bg 7676      # https://<имя-пк>.<tailnet>.ts.net → http://127.0.0.1:7676
   ```
   Сервер остаётся на `127.0.0.1`, наружу смотрит только Tailscale.
4. На телефоне откройте `https://<имя-пк>.<tailnet>.ts.net/home?token=<токен>`.

**Свой сертификат (mkcert, Caddy).** Только в домашней сети. Сертификат локального центра сертификации нужно установить на телефон.

```sh
mkcert -install && mkcert pc.lan 192.168.1.10      # → pc.lan+1.pem и pc.lan+1-key.pem
```

В `config.toml`:

```toml
host = "0.0.0.0"
token = "..."
ssl_certfile = "/путь/pc.lan+1.pem"
ssl_keyfile = "/путь/pc.lan+1-key.pem"
```

Корневой сертификат (`mkcert -CAROOT` → `rootCA.pem`) установите на телефон: Android — Настройки → Безопасность → Шифрование и учётные
данные → Установить сертификат → Сертификат ЦС. Откройте порт 7676 в файрволе ПК только для домашней сети.

### 3. Установка

- **Android, Chrome:** откройте адрес → меню ⋮ → «Установить приложение» (или «Добавить на гл. экран»).
- **iPhone, Safari:** «Поделиться» → «На экран Домой».

## Как это устроено

- `/manifest.webmanifest` — название, иконки (`static/icons/`), стартовая страница `/home`, ярлыки «Инвентарь», «События», «Роллы».
- `/sw.js` (файл `static/sw.js`) — service worker на весь сайт. Стратегия «сначала сеть»: если сервер ответил за 4 с, показывается свежее
  и сохраняется в кэш, иначе — последняя сохранённая копия страницы или ответа API. Без связи в шапке горит «нет связи».
  Кэш привязан к версии (`fo76db-<версия>`), после обновления старый удаляется.
- В кэше остаётся не больше 120 записей сверх предзагрузки: самые старые удаляются.
- Не кэшируются запросы, меняющие данные (POST/DELETE), `/api/tasks` и `/login`. Изменения без связи не сохраняются.
- На узком экране меню прокручивается вбок, таблицы — по горизонтали.

## Ограничения

- Без связи доступны только страницы и данные, которые уже открывались на этом устройстве.
- Уведомления приходят на компьютер (`watch`) и в браузер, пока вкладка открыта (Notification API, опрос раз в 30 с); push-уведомлений при закрытой вкладке и на телефон нет.
- Таблицы рассчитаны на широкий экран: на телефоне удобнее всего «Главная», поиск «Где лежит?», «События» и «Роллы».
