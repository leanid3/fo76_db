# Инструкция пользователя

Пошаговое руководство «с нуля». Справочник по каждой странице — в [user-guide.md](user-guide.md), термины — на странице «Глоссарий» (ссылка в подвале), схема устройства — в [app-map.md](app-map.md).

## 1. Что понадобится

- Fallout 76 (Steam, Xbox, Bethesda.net), установленный на этом же компьютере: из `Data/` читаются `SeventySix.esm` и `SeventySix - Localization.ba2`.
- Интернет для первого наполнения (≈1 ГБ один раз для истории версий) и 2 ГБ свободного места.
- Для инвентаря и легендарных модов — моды: [Invent-O-Matic Stash (Unofficial)](https://www.nexusmods.com/fallout76/mods/2335) с включённой выгрузкой (Extract) и [Improved Workbench](https://www.nexusmods.com/fallout76/mods/2576). Без них работают каталог, события и схемы вручную.
- 7-Zip (`7z`) — только при запуске из исходников или пакета; в сборки, Docker и Flatpak он уже входит.

## 2. Установка и запуск

Выберите один вариант (подробности — [packaging.md](packaging.md)):

| Вариант | Запуск |
|---|---|
| Windows, окно | `fo76db-desktop-windows-x86_64.exe`, двойной клик |
| Linux, окно | распаковать `fo76db-desktop-linux-x86_64.tar.gz`, `./fo76db-desktop/fo76db-desktop` |
| Windows / Linux, в браузере | `fo76db-windows-x86_64.exe` или `./fo76db-linux-x86_64` — откроется сервер и браузер |
| Flatpak | `flatpak install --user --bundle fo76db-linux-x86_64.flatpak`, затем «FO76 DB» в меню |
| Arch / CachyOS | `cd packaging/arch && makepkg -si` |
| Docker | `docker compose up -d`, затем `http://127.0.0.1:7676` |
| Python | `pip install .`, затем `fo76db serve --open` |

Адрес интерфейса — `http://127.0.0.1:7676/home`. Повторный запуск при работающем сервере просто открывает страницу.

## 3. Первый запуск

1. Откройте **Главная**. Пока база пуста, вверху показан мастер первого запуска: папка игры → каталог → выгрузка инвентаря → события.
2. **Папка игры.** Обычно находится сама (Steam, Proton, Xbox, Bethesda.net). Если нет — «Настройки → Пути игры»: «Обзор…» или впишите путь к `Data`, где лежит `SeventySix.esm`, и нажмите «Сохранить пути».
3. В блоке **«Данные»** на главной по очереди нажмите:
   - «Каталог» — ≈1 мин, список предметов и названия EN/RU;
   - «История» — первый раз ≈15 мин и ≈1 ГБ, подтверждение запрашивается (после патча игры — только новые версии);
   - «События» — календарь, Минерва, сезоны.
   Одновременно идёт одна задача; ход виден в журнале ниже.
4. Если что-то не получилось — «Настройки → Диагностика → Проверить»: список проблем и подсказки. То же в терминале: `fo76db doctor`.

## 4. Инвентарь

1. Установите моды (раздел 1) и в игре включите выгрузку Extract в Invent-O-Matic; зайдите в игру за каждого персонажа и выгрузите инвентарь/тайник.
2. Файлы `itemsmod.json` и `LegendaryMods.ini` импортируются **сами**, если запущено слежение (десктоп-версия, `fo76db serve --watch`, `fo76db watch`), либо кнопкой «Импорт выгрузок» на главной.
3. На главной появятся карточки персонажей; цвета и подписи, а также пометка «Склад» (мул) — в «Настройки → Профили и теги».
4. Проверка модов: «Настройки → Моды → Проверить / найти». Если мода нет, страницы, которым он нужен, покажут жёлтое предупреждение.

## 5. Ежедневная работа

- **Выберите персонажа** в шапке (запоминается): по нему показывается «Изучено» везде.
- **Каталог** — поиск по-русски и по-английски (`*` и `?` — шаблоны), фильтры, «добавлено в обновлении». Клик по предмету — карточка: статы, крафт, «как получить» (списки добычи, места), вики.
- **Вишлист и теги** — кнопки в карточке и в таблицах; «★ Сохранённые» — запомнить набор фильтров.
- **Инвентарь** — «где лежит?» по всем персонажам и тайнику.
- **Схемы** — отметка «изучено»; «Передать и продать» подсказывает, какую схему изучить, кому передать, что продать.
- **Роллы** — какие легендарные эффекты нужны; оценка «год-ролл / частично / на скрип»; уведомление о новых совпадениях.
- **Вес** — куда уходит вес и что убрать.
- **События** — сегодняшние сбросы, Daily Ops, чек-лист ежедневок, Минерва (сколько схем не изучено), календарь.
- **История** — снимки выгрузок и сравнение двух.
- **Таблицы** — «☰ Колонки», экспорт CSV/JSON; фильтры отражаются в адресе страницы, ссылку можно сохранить.

## 6. Правила Invent-O-Matic (необязательно)

Страница **IOM** редактирует `inventOmaticStashConfig.json` — это единственное место, где утилита пишет в файлы игры.

1. Внесите правки (или «Скачать черновик», если писать в игру не нужно).
2. «Проверить» — ошибки блокируют запись.
3. «Записать в игру…» показывает список изменений; подтверждение — «Записать в игру».
4. Перед записью делается копия в `<папка бэкапов>/_backup_<дата>/`; «Откатить к бэкапу…» возвращает выбранную версию.

Подробнее — [iom-editor.md](iom-editor.md).

## 7. Доступ с телефона и по сети

«Настройки → Доступ по сети» → «Локальная сеть», «Сохранить», перезапустите `serve`. Появятся токен и ссылка `http://<адрес>:<порт>/home?token=…` — откройте её на телефоне. Для установки как приложение (PWA) нужен HTTPS — [pwa.md](pwa.md). Раздел виден только на самом компьютере.

## 8. Резервные копии и обновление

- **Копия базы:** «Настройки → Диагностика и копия базы» («Скачать копию базы» или «Сохранить копию в data/») либо `fo76db backup`. В базе ваши теги, вишлист, роллы, «изучено», чек-лист и история снимков — её копировать стоит.
- **После патча игры:** «Каталог», затем «История» (или `fo76db catalog`, `fo76db history`).
- **Новая версия утилиты:** о выходе релиза сообщит баннер вверху страниц (и уведомление при работающем `watch`); замените файл/пакет; данные в папке `data/` (в сборках — `~/.local/share/fo76db`, `%LOCALAPPDATA%\fo76db`) сохраняются, схема базы обновляется сама.

## 9. Если что-то не работает

| Симптом | Что делать |
|---|---|
| Каталог пуст, «не найден SeventySix.esm» | «Настройки → Пути игры»: укажите папку `Data` |
| «Каталог» / «История» сразу сообщают про 7-Zip | установите `7z` (Linux: `p7zip`/`7zip`; Windows: 7-Zip) |
| Нет инвентаря | «Настройки → Моды»: найден ли файл выгрузки; нажмите «Импорт выгрузок»; в игре выгрузите инвентарь |
| События не обновились | «События → ⟳ Обновить», причина — в журнале («Настройки → Журнал приложения») |
| Порт 7676 занят другой программой | `fo76db serve --port <другой>` или `port` в `config.toml` |
| Телефон не открывает страницу | режим «Локальная сеть», тот же Wi-Fi, ссылка с токеном; брандмауэр |
| Таблица выглядит странно после обновления | «☰ Колонки → Сбросить вид» |
| Не знаю, что сломано | «Настройки → Диагностика → Проверить» или `fo76db doctor` |

Журнал — `data/app.log` («Настройки → Журнал приложения»: фильтр, «Скачать»). Сообщить об ошибке можно в issues репозитория, приложив журнал.

## 10. Ограничения

- Утилита неофициальная, не связана с Bethesda. Файлы игры не распространяются и не изменяются (кроме конфига IOM по вашему подтверждению).
- Данные событий берутся со сторонних сайтов; при их изменении разбор может временно не работать — старые данные остаются.
- Лицензия — GNU AGPL v3 или новее.
