## Интеграция: Steam / SteamDB (Fallout 76, appid 1151340)

Разбор от 2026-10-05. Сам steamdb.info отдаёт 403 (Cloudflare), поэтому его страницы не читались, а разделы описаны по памяти.
Вместо него берутся публичные Steam API без ключа (проверены `curl`-ом/запросом, отвечают):

| API | Что отдаёт |
|---|---|
| `api.steampowered.com/ISteamUserStats/GetNumberOfCurrentPlayers/v1/?appid=1151340` | Онлайн сейчас (на момент проверки ~8400). Истории нет — копить самим. |
| `api.steampowered.com/ISteamNews/GetNewsForApp/v2/?appid=1151340` | Новости: `title`, `date`, `feedlabel`, `url`, `tags`. Официальные Update Notes — `feedlabel` «Community Announcements», `tags` = `patchnotes`. |
| `store.steampowered.com/api/appdetails?appids=1151340` | Цена и скидка, DLC (3 шт.), издания, 72 достижения, число рекомендаций. |
| `GetGlobalAchievementPercentagesForApp` | Процент игроков по каждому достижению (без ключа). |
| `GetPlayerAchievements` | Свой прогресс; нужен Steam Web API key и публичный профиль. |

Сейчас Steam в проекте используется только для поиска папки игры (`fo76db/gamepaths.py`, `STEAM_APPID`).

### Идеи на основе специфики SteamDB (платформенные данные, временные ряды, трекинг изменений)

1. **Календарь активности.** Тепловая карта онлайна по часам и дням недели из собственных замеров; подсказка «лучшее время для Daily Ops».
2. **Пульс события.** Как менялся онлайн в прошлых Fasnacht, Scorched, Минерве; оценка наплыва к новому событию.
3. **Патч-дозор.** Один виджет: текущий BuildID, последний патч (из news), «предметов добавлено», «ваши схемы, ставшие доступными».
4. **Дифф «до/после патча» для инвентаря.** Снимки `inv_snapshots` в `/history` помечаются датой патча; видно, что изменилось после обновления.
5. **Трекер цен Atom Shop** по образцу вишлиста SteamDB — отдельная тема, см. «Расписание Atom Shop» выше.

### Сделано (2026-10-06, см. `CHANGELOG.md`)

Лента патчей + уведомление, онлайн (замеры и график), «ваша сборка» из `appmanifest`, событие при смене BuildID. Из таблицы выше остались идеи:
Price history, Packages / DLC, Achievements, календарь активности и «пульс события» (нужны накопленные замеры онлайна), дифф инвентаря «до/после патча», «патч-дозор» одним виджетом.

### Что осталось

1. Достижения (опционально, нужен Steam API key в `config.toml`): `GetGlobalAchievementPercentagesForApp` + `GetPlayerAchievements`.
2. Тепловая карта онлайна по часам и дням недели — когда накопится хотя бы месяц замеров.

Ограничения: у API нет истории онлайна (копится только с момента запуска `watch`), онлайн — только Steam; детали интерфейса SteamDB не сверены.
