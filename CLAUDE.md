# CLAUDE.md

Утилита fo76db: локальная база Fallout 76 (FastAPI + SQLite + Tabulator). Пользователь общается по-русски, документация на русском.

## Документация — обновлять после каждого изменения

Любое изменение поведения, страниц, API, схемы БД, настроек или команд в том же заходе отражается в документации:

| Что изменилось | Куда писать |
|---|---|
| Любое изменение | `CHANGELOG.md` — запись под текущей датой (Добавлено / Изменено / Исправлено) |
| Страница, фильтр, кнопка, колонка | `docs/user-guide.md` |
| Модуль, таблица БД, миграция, API, помощник `app.js` | `docs/architecture.md` |
| Источник данных, правило импорта или расчёта | `docs/data.md` |
| Редактор IOM | `docs/iom-editor.md` |
| Команды, установка, список страниц | `README.md` |

Документация описывает то, что есть в коде. Перед записью сверяйте названия кнопок и полей с шаблонами.

## Правила

- **Игру и пресеты утилита только читает.** Единственное исключение — запись конфига IOM (`fo76db/iomconfig.py`): только по явному подтверждению, с бэкапом в `/games/fallout76configs/_backup_<ГГГГММДД>/` и с сохранением inode (файл — жёсткая ссылка).
- **Перед разовой правкой данных в БД** — копия через `sqlite3 data/fo76.sqlite ".backup …"`. Не `cp`: база в режиме WAL.
- **Новые колонки** добавляются через `MIGRATIONS` в `db.py`, **разовые правки данных** — в `_migrate()` под флагом в `meta`.
- **После правки Python-кода** перезапустить `serve` и `watch`.
- **Коммиты** — только по просьбе пользователя.
- **Код без лицензии** (например, Inventory Viewer) не копировать: только своя реализация по описанию.

## Смежные проекты (только чтение)

- `/games/fallout76configs` — пресеты ini и моды (свой CLAUDE.md). `sResourceArchive2List` в `Fallout76Custom.ini` задаёт набор и порядок модов; таблица модов — `docs/mods.md`. Не понижать `fLODFadeOutMult*` (=100).
